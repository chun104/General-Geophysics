# 🌍 地球物理通論 (General Geophysics) - 課程介紹網頁

這是臺北市立大學「地球環境暨生物資源學系」第115學年第1學期「地球物理通論」的課程介紹網站。本網頁採用 Google Material Design 風格設計，提供互動式的課程大綱、AI 工作流圖解與課程目標說明。

## 📌 課程資訊

* **授課教師**：陳達毅 (Instructor)
* **開課班別**：地生系二
* **課程類型**：跨領域課程、問題導向/專題導向課程、實作課程
* **領域分類**：STEAM (自然科學、資訊通訊科技) / SDGs (促進具包容性的永續工業化及推動創新)

## 🎯 三大核心目標

1. **地球物理學科知識**
   熟悉震測、重力、地熱、地電、地磁與板塊構造等地球物理方法與原理，結合野外實驗與專題演講。
2. **培養英文能力**
   學習與課程相關的英文單字與句型，對英文句型進行分析與分類，以全英文進行報告與知識探索。
3. **培養資訊能力**
   學習使用免費平台 (GitHub, HuggingFace, Google Colab)、AI 代理工具 (Hermes Agent, Antigravity, Opencode) 以及資料庫 (Notion, NotebookLM) 來提升效率並製作專題網頁。

## ⚙️ 技術與工具 (Tech Stack)

* **前端技術**：HTML5, CSS3, Google Material Symbols & Fonts
* **網頁代管**：GitHub Pages
* **課程應用工具**：
  * Python, PyGMT (全球地圖繪製)
  * Telegram 排程機器人
  * AI Agents (Hermes Agent, Antigravity)

## 🚀 如何部署 (Deploy)

本專案透過 GitHub Pages 自動部署：
1. 將 `index.html` 上傳至 GitHub `main` 分支。
2. 至專案 `Settings` > `Pages`。
3. 將 Source 設為 `Deploy from a branch` 並選擇 `main`，點擊儲存即可生成靜態網頁。
